# 松贴 Songtie

> 记录只是把念头放下来，不是对未来作出承诺。

松贴是一面常驻在桌面里的有限便利贴墙。突然想到什么时，你可以先随手记下，然后继续眼前的事情；想认真梳理时，再打开整面墙，自由摆放、书写和涂画。

墙面不会无限延伸。便利贴变多、空间开始拥挤，并不表示你欠下了很多任务，而是在提醒你：想法已经有些多了，可以停下来整理、选择优先级，或者放心地丢掉一部分。

### 安装

松贴当前支持 **Ubuntu 22.04、x86_64**。

##### 使用 `.deb` 安装（推荐）

下载 `songtie_0.1.0_amd64.deb`，在文件所在目录打开终端，运行：

```bash
sudo apt install ./songtie_0.1.0_amd64.deb
```

安装完成后，从应用列表启动“松贴”一次即可。

##### 使用 AppImage

AppImage 的开机启动和桌面快捷方式会记住文件位置，因此请在**第一次运行前**把它放进准备长期使用的固定目录，例如 `~/Applications/松贴/`，之后不要随意移动。

假设文件名为 `songtie_0.1.0_amd64.AppImage`，进入它所在的固定目录后运行：

```bash
chmod +x ./songtie_0.1.0_amd64.AppImage
./songtie_0.1.0_amd64.AppImage
```

如果下载到的文件名不同，请在命令中换成实际文件名。

### 常驻方式与入口

松贴启动后会**安静地常驻系统托盘**，不会在开机时主动弹出墙面。首次正常运行后，它会随系统开机启动。

托盘菜单提供四个入口：

- **当前墙**：打开整面便利贴墙；
- **随手贴**：打开快捷记录框；
- **完成陈列**：查看已经完成并留下的便利贴；
- **退出松贴**：保存并真正结束程序。

也可以使用全局快捷键：

- `Ctrl + Alt + N`：打开随手贴；
- `Ctrl + Alt + M`：打开当前墙。

如果快捷键已被系统或其他软件占用，仍然可以从托盘进入，不影响使用。

### 随手记录一个念头

1. 按 `Ctrl + Alt + N`，或从托盘选择“随手贴”。
2. 直接输入内容。界面会根据文字占用空间，自动判断使用小、中、大三种纸片中的哪一种。
3. 按 `Ctrl + Enter`，或点击“贴上去”。便利贴会自动出现在当前墙上，窗口随即收起。

如果内容放不进大纸片，松贴会拒绝生成便利贴，并保留已经输入的全部内容。删减到能够完整显示后，再次提交即可；松贴不会自动拆分、缩小文字或隐藏内容。

### 使用当前墙

当前墙打开后就是一整块有限的全屏空间，没有隐藏在外面的区域，也不能无限缩放或扩展。

##### 摆放便利贴

- 在“摆放”模式中拖动便利贴，自由安排位置；
- 靠近其他便利贴边缘时会有轻微吸附，方便对齐和拼接；
- 点击便利贴，或将焦点移到便利贴后按 `Enter`、`Space`，即可打开检视；
- 点击“新纸片”会创建一张大纸片，并直接进入编辑。

##### 在墙上涂写

切换到“涂写”模式后，可以直接在墙面书写、画线和组织关系，也可以更换墙面背景。墙面涂鸦会保存在便利贴下方，便利贴仍然是可以独立移动的对象。

### 查看和编辑便利贴

打开便利贴时，它会移动到屏幕中央并按固定范围放大，后面的墙面会轻微变暗和模糊。看到的仍然是原来的整张纸片，不会展开成另一种文档。

编辑器提供：

- 选择、画笔、橡皮；
- 文字、直线、箭头；
- 矩形、椭圆；
- 绘图颜色和纸张颜色。

便利贴只有**小、中、大**三种固定尺寸。放大总是可以进行；缩小只有在当前全部内容仍能完整放进目标纸片时才会生效，放不下的尺寸会变为不可选。

##### 键盘基本操作

- 使用 `Tab` 在按钮和输入控件之间移动，按 `Enter` 或 `Space` 激活按钮；
- 画布获得焦点并选中元素后，方向键每次移动 1 个单位，`Shift + 方向键` 每次移动 10 个单位；
- 按 `Delete` 或 `Backspace` 删除选中的绘图元素；
- 选中文字后按 `Enter` 进入文字编辑；
- 按 `Esc` 或点击 `X` 关闭检视。

你还可以给便利贴写上日期和时间。它只是安静地显示在那里：松贴不会提醒、催促、标红，也不会判断是否超时。

### 完成与删除

拖动便利贴时，墙面底部会出现两个不同的出口；在便利贴检视界面中也可以执行相同操作。

- **完成**：便利贴会经过盖章庆祝动画，离开当前墙并进入“完成陈列”；
- **丢掉**：便利贴会经过独立的丢弃动画，从所有普通使用入口彻底消失。

完成陈列中的便利贴保留完成时的原貌，并附有“完成于 YYYY/MM/DD”日期。它们只能查看，不能再次编辑，也不会生成完成数量、连续天数、效率分析或总结。

删除不是失败，只是决定不再为这个念头保留空间。删除后无法在松贴的普通界面中撤销或恢复，请在丢掉前确认这是你想要的告别。

### 保存与隐私

松贴会在本机自动保存墙面、便利贴和完成陈列。你不需要手动管理文件。

它没有账户、云同步、跨设备协作、提醒、统计、总结或 AI 自动整理。内容留在这台电脑上，理解、判断和取舍始终由你完成。

### 收起与退出

在当前墙、完成陈列或便利贴检视中按 `Esc`，或者点击窗口中的 `X`，只是把界面收起；松贴仍然安静地留在托盘中，快捷记录也仍然可用。

只有从托盘菜单选择“退出松贴”，程序才会保存当前内容并真正结束。
